# Contributing to Axithor Risk AI

Thanks for your interest in this project.

## Before You Contribute

This repository is **not open for unrestricted reuse or contribution**.

Because the project is released under an **all rights reserved / permission required** license, you must get approval from the repository owner before:

- using the code in another project
- submitting major code changes
- redistributing modified versions
- deploying the software publicly
- using it for commercial or academic reuse

## How to Request Permission

Please contact the repository owner first and include:

- who you are
- how you want to use the project
- whether the use is personal, academic, or commercial
- whether you want to modify, publish, or deploy it

## Small Improvements

If you want to suggest a typo fix, documentation improvement, or bug report, open an issue first and describe:

- the problem
- the proposed change
- why it helps

Please wait for approval before opening a pull request.

## Development Notes

If permission is granted and you are asked to contribute:

1. Fork or branch from `main`
2. Keep changes focused
3. Add or update tests where relevant
4. Document user-facing behavior changes
5. Avoid committing secrets, API keys, or virtual environment files

## Code Style

- Prefer clear, readable Python
- Keep retrieval and analysis behavior explainable
- Preserve the vectorless RAG design philosophy
- Keep UI changes simple and demo-friendly

## Security

Never commit:

- API keys
- `.env` files
- virtual environments
- local cache or machine-specific files

## Final Note

By contributing, you acknowledge that contribution acceptance is at the sole discretion of the repository owner.
